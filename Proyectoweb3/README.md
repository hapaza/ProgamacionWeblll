
Ignister es una plataforma de comercio electrónico especializada en productos digitales y tecnológicos.

## 🛠️ Tecnologías
- **Backend**: Node.js + Express + PostgreSQL + Redis
- **Frontend**: React + Vite + Context API
- **Infraestructura**: Docker + GitHub Actions

## 📦 Estructura
- 27 tablas en PostgreSQL
- Arquitectura Hexagonal
- 100+ componentes

## 🔧 Instalación
```bash
# Backend
cd backend
npm install
cp .env.example .env
npm run dev

# Frontend
cd frontend
npm install
cp .env.example .env
npm run dev
